## 3. T2：Steam per-app 语言改 schinese（首选）

**为什么可能有效**：商店语言下拉只是 UI 白名单；`ISteamApps::GetCurrentGameLanguage` 返回的是本地 per-app 配置值。游戏语言链只消费这一个值（证据 #3/#9），Steam 侧把它设为 schinese 后，游戏应直接加载 zh 列。

**操作**（全程 `工具\set_steam_language.py`，用户执行）：
1. 完全退出 Steam（托盘→退出）；`python set_steam_language.py status` 确认"未运行"、blob language=english。
2. `python set_steam_language.py apply`——自动备份 localconfig.vdf 与 appmanifest 到 `备份\steam_cfg\`，然后 30B blob 内 `english→schinese` 字节级替换 + appmanifest 两处明文替换。
3. 启动 Steam → 直接运行游戏，观察主菜单语言。
4. **重启后复查**：再跑一次 `status`——若 blob 仍为 schinese 且游戏中文 → 成；若 Steam 把它改回 english（规范化未声明语言）→ T2 失效，回滚并转 T4。

**失败模式**：a) Steam 启动时规范化 blob；b) Steamworks 线上 appinfo 的声明列表在运行时覆盖本地值（get_language 走云端校验）——两者表现相同（status 回 english 或游戏仍英文），都按"转 T4"处理。
**回滚**：`python set_steam_language.py restore`。

## 4. T4：荷兰语覆写（兜底，用户原方案）

**原理**：荷兰语是 Steam 已声明语言（属性页可选），游戏按**列名**读 TSV（gcl 符号 `localization_table_util.find_column`）。脚本把 5 个 TSV 表头的 `zh` 与 `nl` 两个单元格互换（等长交换、数据行零改动、UTF-8 无 BOM/CRLF 不变）→ 选荷兰语 = 读 zh 列官方简中。

**操作**（`工具\dutch_zh_switch.py`，用户执行）：
1. 退出游戏；`status` 确认 5 文件"原始"、基线校验通过。
2. `python dutch_zh_switch.py apply`（**先不带字体**——若引擎有逐字回退，直接就成）。
3. Steam → 属性 → 语言 → **荷兰语（Nederlands）** → 启动游戏。
4. 若显示豆腐块/缺字：`python dutch_zh_switch.py apply --with-font`（备份后用 noto_sans_sc 覆盖 noto_sans_regular；SC 字体含拉丁字形，英文数字照常渲染）。
5. 若连荷兰语都不生效（get_language 忽略属性选择）→ T4 失效，`restore` 回滚。

**注意**：
- 游戏更新或"验证文件完整性"会还原文件 → 重跑 apply 即可（脚本会先校验基线防版本错配，版本变了先按 [基线\基线说明.md](基线/基线说明.md) 再冻结并更新脚本内 BASE_SHA）。
- 此状态下 zh-TW 列原内容仍在 nl 之外的正常位置不受影响；繁中用户不受影响（本方案只动简中阅读者自己）。
**回滚**：`python dutch_zh_switch.py restore`（5 TSV 按基线还原 + 字体还原），并把 Steam 语言选择改回 English。
