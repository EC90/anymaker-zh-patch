# Anymaker 汉化工程（校对+差异补丁型）

围绕 Anymaker（Steam AppID 4435340）中文本地化的工作工程。**事实认知与工作区规则以 [..\AGENTS.md](../AGENTS.md) 与 [..\数据库\README.md](../数据库/README.md) 为上位权威，本目录只维护工程自身流程。**

## 定位（2026-09-21 确立）

实测发现**官方简繁中文已内置**（5 个语言 TSV 的 zh/zh-TW 列覆盖率≈100%、Noto Sans SC/TC 字体随包），本工程因此不是"从无到有的汉化"，而是：

> 以官方中文为基底做**校对/润色**，产出**差异补丁（diff）**经 **GitHub** 发布（术语表+补丁+本地安装脚本），勘误回馈官方；**创意工坊**待官方开放语言类物品后跟进。

依据与完整论证：[01_可行性研究.md](01_可行性研究.md)。
